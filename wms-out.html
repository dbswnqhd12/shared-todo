WMS 반출 복사

WMS 반출 화면의 내용을 즐겨찾기 버튼 하나로 복사해서, 사이트 반출 탭에 붙여넣으면 칸이 자동으로 채워져요. 설치는 필요 없어요.

1. 아래 파란 버튼을 즐겨찾기 바로 끌어다 놓기

GWJ3 반출 복사

즐겨찾기 바가 안 보이면 Ctrl + Shift + B 를 누르세요.

2. 사용하기
  1. WMS에서 반출 건(그룹) 상세 화면을 엽니다
  2. 즐겨찾기 바의 GWJ3 반출 복사를 누르면 "복사했어요"가 떠요
  3. GWJ3 사이트 → IST → 반출 → WMS 붙여넣기를 누르고 Ctrl + V
  4. 미리보기를 확인하고 추가를 누르면 끝이에요

화면 일부만 가져오고 싶으면 그 부분을 마우스로 드래그해 둔 채로 버튼을 누르세요. 버튼 없이 표를 드래그해서 Ctrl + C 한 것도 붙여넣을 수 있어요.

이 버튼은 보고 있는 화면의 글자를 클립보드에 복사만 해요. WMS를 바꾸거나 다른 곳으로 보내지 않아요.
